# سند معماری، ساختار و مشخصات ۱۰ صفحه وبسایت ای‌آی تونل (Toonel AI)

نقشه فنی و اجرایی طراحی رابط و تجربه کاربری (UI/UX) بر اساس نیازمندی‌های محصول و هویت برند.

## چارچوب طراحی و اصول هویتی

- **اصلاحات محصولی کلیدی:**
  1. ساده‌سازی دسترسی به دو مدل **اشتراک جامع** و **خرید تک‌دوره**
  2. نقش مشاور غیراجباری دستیار **«نِل» (Nel)**
  3. اتصال مستقیم ویدیوهای کوتاه به تالار گفت‌وگو
  4. یکپارچه‌سازی امتیازات با تخفیف تمدید
- **لحن متون:** صمیمی (خطاب «تو»)، شفاف و به‌دور از اغراق.

| شاخص هویت و محصول | استاندارد اجرایی در طراحی و محتوا |
| :--- | :--- |
| **ایده مرکزی و قول برند** | خروج از سردرگمی آموزشی؛ کمک به پیدا کردن مسیر درست، یادگیری قدم‌به‌قدم و به‌کارگیری هوش مصنوعی در کار و زندگی. |
| **پالت رنگی رسمی** | سرمه‌ای عمیق (`#141A3A`)، کاغذی روشن (`#F7F5F0`)، زرد تونل برای اقدام اصلی (`#FFC53D`) و آبی مسیر (`#5B7CFF`). |
| **الگوی نام‌گذاری محتوا** | دوره‌های جامع با قالب `«[کار] با هوش مصنوعی»` (مثل «گزارش‌نویسی با هوش مصنوعی») و ویدیوهای کوتاه با قالب `«یک کار، یک دقیقه»`. |
| **دستیار هوشمند «نِل» (Nel)** | ماشین زمان کوچک با نور زرد؛ همراه کنجکاو و گرم که بدون اجبار یا قفل‌کردن مسیر، پیشنهاد آموزشی متناسب با هدف و زمان کاربر می‌دهد. |
